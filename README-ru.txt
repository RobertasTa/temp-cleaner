=====================================================================
  TEMP CLEANER - безопасный очиститель временных файлов Windows
=====================================================================

ЧТО ЭТО
-------
Программа находит скопления временных файлов в Windows и помогает
очистить их БЕЗОПАСНО. Каждое найденное место получает цвет риска,
а каждое решение (удалено / пропущено и ПОЧЕМУ) записывается в
журнал - никаких тихих действий.

А НУЖНА ЛИ ОНА ВАМ ВООБЩЕ?
--------------------------
Честный ответ: если вы хотите чистить только СИСТЕМНЫЙ мусор
Windows (остатки обновлений, корзину, миниатюры) - для этого
достаточно встроенного Storage Sense, мы вам не нужны. Эта
программа - ДОПОЛНЕНИЕ к инструментам Windows, а не замена: она
чистит кэш-джунгли ваших ПРОГРАММ (браузеры, Electron-приложения,
пакетные менеджеры, sync-клиенты), которых Storage Sense не видит.
Живое измерение на машине разработчика: 440 мест мусора / 31 ГБ,
из которых встроенные инструменты покрыли 0,2 % (ваши числа будут
меньше - суть в слепой зоне, а не в размере). И ещё один честный
факт: чистка temp-файлов - это гигиена диска, а не ускорение
компьютера.

ЦВЕТА
-----
  ЗЕЛЁНЫЙ - проверенные безопасные места (TEMP, Windows\Temp,
            NVIDIA DXCache, кэш pip, кэш Chrome) - можно чистить
            одной кнопкой.
  ЖЁЛТЫЙ  - найдено эвристикой (папки temp/tmp/cache/logs) -
            чистится только после вашего подтверждения.
  КРАСНЫЙ - в пути или внутри есть опасное слово (models, data,
            profiles, backup, save, config) - ТОЛЬКО просмотр,
            кнопка очистки отключена.

КАК ЗАПУСТИТЬ
-------------
1. Нужен только один файл: TempCleaner.exe (язык интерфейса -
   английский или литовский - переключается в самой программе).
   Без установки, без Python - работает прямо с флешки.
2. Первый запуск занимает несколько лишних секунд - это нормально.
3. Если Windows покажет синее окно SmartScreen - нажмите
   "More info" -> "Run anyway". Программа не подписана
   (самодельная), но безопасна.

КАК ПОЛЬЗОВАТЬСЯ (по шагам)
---------------------------
1. "Scan" - программа в фоне осматривает временные места и
   показывает таблицу с размерами и цветами.
2. "Preview (what would be deleted)" - ПЕРЕД очисткой видно,
   сколько файлов и МБ будет удалено с текущим порогом возраста.
   НИЧЕГО не удаляется - это только предпросмотр.
3. Ползунок возраста (1-30 дн.) - удаляются ТОЛЬКО файлы старше
   выбранного порога (по умолчанию 7 дней; то же правило
   использует Windows Disk Cleanup). Свежие файлы могут
   принадлежать работающим программам - они не трогаются.
4. "Clean all GREEN locations" - чистит все ЗЕЛЁНЫЕ места
   (после подтверждения).
5. Кнопка Clear в строке чистит одно конкретное место.
6. Двойной щелчок по строке открывает папку в Проводнике -
   можно посмотреть глазами перед очисткой.
7. НОВОЕ в v1.1: правый клик по строке -> "What is this?" - для
   известных программ браузер открывает ОФИЦИАЛЬНУЮ страницу
   производителя (локальный справочник, 66 записей), для
   неизвестных - поиск Google. Приватность: в запрос уходит ТОЛЬКО
   имя программы - никогда полный путь и никогда ваше имя
   пользователя. В том же меню - "Copy path" и "Open folder".
8. В углу счётчик "Total freed" - сколько места программа уже
   освободила за все очистки.

ЧТО НИКОГДА НЕ УДАЛЯЕТСЯ (предохранители)
-----------------------------------------
  * Файлы моложе порога возраста            -> журнал: SKIPPED AGE
  * Занятые (используемые) файлы            -> журнал: SKIPPED LOCKED
  * Junction/symlink ссылки и всё за ними   -> журнал: SKIPPED JUNCTION
  * Структура папок (удаляются только файлы)
  * КРАСНЫЕ места (очистка отключена)

ЖУРНАЛ
------
Каждая очистка дописывается в valymo_log.txt: что удалено, что
пропущено и ПОЧЕМУ, сколько места освобождено. Любое действие можно
проверить в любой момент. Где живёт журнал - см. ПОРТАТИВНЫЙ РЕЖИМ.

ПОРТАТИВНЫЙ РЕЖИМ
-----------------
Флажок сверху, рядом с ползунком возраста:
  ВЫКЛЮЧЕН (по умолчанию) - журнал и рабочие файлы хранятся на
    компьютере, в %LOCALAPPDATA%\TempCleaner.
  ВКЛЮЧЁН - всё хранится в папке _darbal РЯДОМ с программой
    (например, на флешке), и на компьютере НЕ остаётся следов -
    программа даже удаляет свою ранее созданную папку %LOCALAPPDATA%.
Выбор запоминается файлом TempCleaner_portable.txt рядом с exe (конвенция
Notepad++ / VS Code) - он путешествует вместе с флешкой, поэтому
режим действует на любом компьютере.

ЯЗЫК
----
Язык (Lietuviu / English) переключается прямо в программе -
выпадающий список сверху. Выбор запоминается (в портативном режиме
путешествует с флешкой) и применяется после перезапуска.

СПРАВОЧНИК МЕСТ (для продвинутых)
---------------------------------
В файле vietos.json перечислены зелёные места, чёрный список и
имена папок для эвристики - можно добавить свои. Если файл
повредить, программа просто вернётся к встроенным значениям.
